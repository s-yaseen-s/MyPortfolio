# Yaseen Bilal — Portfolio Website

A static personal portfolio website presenting Yaseen Mohammed Bilal, selected projects, skills, and contact links. The page uses a dark visual theme with responsive layouts and client-side interactions.

## Contents

- `index.html` — portfolio sections, project cards, skills, navigation, and contact form interface
- `MyProfile.jpg` — profile image used on the page

## Built with

- HTML5
- Tailwind CSS via CDN
- Custom CSS and JavaScript
- Font Awesome and Google Fonts via CDN

## Run locally

Open `index.html` in a modern browser. Alternatively, start a simple local server in the repository directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Contact form

The contact form is configured to submit through FormSubmit's AJAX endpoint. Its behavior depends on that external service and network access. Review the endpoint and privacy implications before using this page in production.

## Customization

Edit the content and project links in `index.html`. Replace `MyProfile.jpg` to use a different profile image, keeping the filename or updating the image reference.
